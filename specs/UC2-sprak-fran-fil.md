# UC2 – Språken läses från filen

**Som** användare **vill jag** att programmet läser språken från rubrikraden, **så att** varje `Word` får rätt `LanguageIn` och `LanguageOut`.

## Acceptanskriterier
- [x] Inga hårdkodade `"swedish"` eller `"english"` finns kvar i koden
- [x] Byter jag rubriken till `svenska,engelska` får orden de språken

## Koncept
`lines[0].Split(",")`, index i arrayer
